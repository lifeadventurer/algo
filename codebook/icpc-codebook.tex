\newcommand{\SnippetOnPage}[2]{%
  \ifnum\getpagerefnumber{snippet-start-#1}>0\relax%
    \ifnum\getpagerefnumber{snippet-start-#1}>\value{page}\relax%
    \else
      \ifnum\getpagerefnumber{snippet-end-#1}<\value{page}\relax%
      \else
        \SnippetSeparator\hyperref[snippet-start-#1]{#2}%
        \def\SnippetSeparator{,\allowbreak\ }%
        \def\SnippetFound{1}%
      \fi
    \fi
  \fi
}

\textbf{How to use.} Copy only the pieces you need into the contest starter.
All snippets assume \texttt{\#include <bits/stdc++.h>}, \texttt{\#include <cassert>}, and
\texttt{using namespace std;} unless they already include them.
GNU extensions are used for PBDS and 128-bit integers. Added snippets use
0-based indices and half-open ranges unless stated otherwise; original
templates retain their own conventions. Read the note above each listing.
Dependencies are named explicitly. This book includes every C++ source in
the template directories and the debug header, directly from the repository.
\par
\textbf{Printing.} A4, two columns, numbered pages. Print at actual size.
\textcolor{codeblue}{Keywords}, \textcolor{codered}{comments}, and
\textcolor{codegreen}{strings/characters} use subtle syntax colors.
Full coverage, with no page cap.
Page headers list the source snippets on that page and link to their entries.
Each entry includes a usage example, source line count, and a 12-hex-character SHA-256
fingerprint of the exact source file.
